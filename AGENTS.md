# MacroForge

Vanilla JS + Three.js app built with Vite.

- Dev server: `npm run dev`
- Production build (verification): `npm run build`

Structure: `src/calc.js` (nutrition engine), `src/foods.js` (food DB, sample-day solver, guides), `src/scene.js` (Three.js background), `src/ring3d.js` (3D macro ring), `src/main.js` (UI wiring), `src/style.css`.
